# A Comparative Study of Deep Learning Architectures for Multi-Class News Topic Classification

## Course
ICT-4442 – Deep Learning Project

## Project Overview
This project compares four deep learning architectures for multi-class news topic classification using the AG News dataset.

## Models Implemented
1. Multi-Layer Perceptron (MLP)
2. One-Dimensional Convolutional Neural Network (1D-CNN)
3. Bidirectional Long Short-Term Memory (BiLSTM)
4. Transformer Encoder

## Dataset
AG News Classification Dataset

The dataset contains four categories:
- World
- Sports
- Business
- Science/Technology

## Evaluation Metrics
- Accuracy
- Macro Precision
- Macro Recall
- Macro F1-score
- Training Time
- Inference Time
